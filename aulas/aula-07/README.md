# Aula 07 — Filas

**Disciplina:** Algoritmos e Estruturas de Dados II  
**Professor:** Prof. Dr. Dilermando Piva Jr.

Capítulo 7 — Filas, com cinco exercícios e dois projetos práticos.

## Conteúdo

- Princípio FIFO
- `enqueue()`, `dequeue()`, `peek()`, `is_empty()` e `size()`
- Fila de impressão
- Duas filas com prioridade
- Projeto: gestão de tarefas
- Projeto: fila de cinema
