# Aula 08 — Listas Encadeadas

**Disciplina:** Algoritmos e Estruturas de Dados II  
**Professor:** Prof. Dr. Dilermando Piva Jr.

Capítulo 8 — Listas Encadeadas, com sete exercícios e dois projetos práticos.

## Conteúdo

- Nó (`Node`) e referência `next`
- `head` como início da lista
- Inserção na cabeça
- Remoção por valor
- Busca sequencial e complexidade O(n)
- Percurso e contagem de nós
- Ponteiros lento e rápido
- Reversão de lista
- Lista duplamente encadeada com `prev` e `next`
- Playlist com navegação para frente e para trás
- Histórico de navegador
