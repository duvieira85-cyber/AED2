# Aula 05 — Programação Orientada a Objetos (POO)

Exercícios práticos do Capítulo 5.

## Exercícios

1. `exercicio-01-classe-pessoa.py` — classe Pessoa, `__init__`, método de instância e `__str__`.
2. `exercicio-02-encapsulamento-lampada.py` — encapsulamento com atributo privado e métodos controlados.
3. `exercicio-03-heranca-animal.py` — herança e sobrescrita de método.
4. `exercicio-04-polimorfismo-animais.py` — polimorfismo usando uma função genérica.

Os códigos seguem os enunciados e exemplos do material do Capítulo 5.
