# Aula 06 — Pilhas

**Disciplina:** Algoritmos e Estruturas de Dados II  
**Professor:** Prof. Dr. Dilermando Piva Jr.

Capítulo 6 — Pilhas, com seis exercícios e dois projetos práticos.

## Conteúdo

- Princípio LIFO
- `push()`, `pop()`, `peek()`, `is_empty()` e `size()`
- Underflow
- Conversão de decimal para hexadecimal
- Balanceamento de delimitadores
- Projeto: histórico de filtros em dashboard
- Projeto: calculadora de expressões aritméticas
