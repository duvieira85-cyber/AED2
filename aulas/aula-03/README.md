# Aula 03 — Vetores Não-Ordenados e Busca Sequencial

**Disciplina:** Algoritmos e Estruturas de Dados II  
**Professor:** Prof. Dr. Dilermando Piva Jr.

Capítulo 3 — Vetores Não-Ordenados — Busca Sequencial.

## Conteúdo

- Melhor caso O(1) e pior caso O(n)
- Busca sequencial em listas não-ordenadas
- Índices iniciados em zero
- Retorno de `-1` para ausência
- Busca da primeira ocorrência
- Contagem de ocorrências
- Remoção com deslocamento dos elementos
- Projeto: catálogo de filmes
- Projeto: lista de convidados
