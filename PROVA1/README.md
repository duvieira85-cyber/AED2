# PROVA 1 — Algoritmos e Estruturas de Dados II

Repositório de apoio para preparação da P1.

## Conteúdos de estudo

- Análise de complexidade: O(1), O(log n), O(n) e O(n²)
- Busca sequencial e busca binária
- Pilhas: LIFO, `append()`, `pop()` e consulta ao topo
- Filas: FIFO, `append()` e `popleft()`
- Listas encadeadas: nós, `head`, `next`, percurso, busca, contagem e remoção
- Implementação e interpretação de código Python

## Objetivo

Concentrar os simulados, exercícios resolvidos e revisões para a P1 em um único local.
