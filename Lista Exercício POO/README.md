# Lista de Exercícios — POO

## Aula 05 — Programação Orientada a Objetos

Esta pasta contém os 10 exercícios da Lista de Exercícios da Aula 05.

Conteúdos trabalhados:
- classes e objetos;
- atributos e métodos;
- encapsulamento;
- herança;
- polimorfismo;
- atributos de classe;
- getters e setters;
- `__init__`;
- `__str__`.

Os códigos foram feitos de forma simples e com comentários para facilitar o estudo.
